# Billiard Training App

A workspace for the Billiard Training App — a Spring Boot + Angular application that helps
billiard players organize shots, practice sessions, and track progress, backed by a
video-analysis pipeline for detecting table shots from footage.

## In this workspace

This folder is the shared IntelliJ workspace root for the whole project. Each subfolder is an
independent git repository with its own remote — see [`CLAUDE.md`](./CLAUDE.md) for the full
map of sibling projects and where to find each one's own documentation.
